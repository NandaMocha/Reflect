# Reflect

An iOS learning journal app. Capture reflections on what you're learning — text, images, voice, video — with iCloud sync and achievement milestones to keep you motivated.

**Stack**: SwiftUI · SwiftData · Swift 6 · iOS 17+ · Xcode 15+ · CloudKit

## Quick start

```bash
open Reflect.xcodeproj
```

In Xcode, pick the **Reflect** scheme and press Cmd+R.
